# PCB绘制流程

## 综述

以目前主流的工作流来讲，PCB 会有两个比较重要的文件：第一个文件是原理图文件，第二个文件是 PCB 文件。

原理图文件本质上是一个声明A连接到B的一种可视化文件。举个例子，比如我们的一片电源降压芯片，它一定有输入和输出。在这个部分，原理图只负责梳理输入和输出应该连接到剩下的电源网络或者其他器件的哪个位置，并且以一直图的形式展示出来，方便人进行处理。

 PCB 文件则是通过原理图，利用EDA厂家的编译器，就可以按照原理图上所标识的内容进行编译，并且把器件封装直接摆放在待处理的区域。器件之间就会有电气连接的指示，通过参考规则和电气规范，将它们连接起来。

本质上来讲，PCB 的绘制就是在多维条件约束下的一个数学求解。但是，很多人（包括现在的大模型厂商） 对PCB 绘制的认知，可能只保留了PCB 阶段，但实际上，我们的处理是从原理图阶段就已经开始了。

回到大模型的阶段，首先，大模型到现在为止处理这些问题，也算不上得心应手，只能说是硬件初学者的基本表现。

但它的优点在于，它的注意力比人类强，可以在 PCB 和原理图的绘制过程中，发现某些电气连接错误；包括编译器编译失败的结果，也可以交由它处理。在这方面，它目前做的是比较得心应手的。所以，以目前大模型绘制 PCB 的实力，我们更倾向于把它作为一个辅助工具。而现在大模型厂商需要实现的，则是从初学者到真正的硬件专家的转变。

既然大模型的训练流程与培养人类的思维并无特别明显的区别，都是要通过不断的实践，从实践中总结经验，学习他人的经验，并把它们融合贯通在一起。所以针对这部分工作，我们需要做的事情其实有很多。

## PCB绘制的流程

下面以我的经验，把整个 PCB 流程进行一个详细的梳理：

无论是什么工程，PCB绘制工作完全围绕着芯片和接口展开的。本质上讲，就是通过不断的调整，在满足<mark>约束条件</mark>的情况下，来确保主芯片跟接口相连。

芯片：SOC、RAM、ROM、电源芯片等等。

接口：屏幕接口、BTB接口（PCB和PCB直接相连）、还有type-c、3.5mm耳机接口等等。

总体上，PCB的绘制流程可以分为：需求确定、硬件选型、电路设计、原理图绘制、原理图编译、结构设计、元器件摆放、电源绘制、模拟电路绘制、数字电路绘制、DRC及穿插在这些环节当中的必要检查构成。下面的具体顺序会按照这个来。

### 需求确定以及硬件选型

当我们拿到需求之后，必须默认需求已经给出了我们需要的芯片、要实现的功能、需要引出的接口，以及其他一些电气要求。

我们要做的第一步，就是根据厂家给出的芯片型号，去对应的平台下载芯片的技术手册和封装。所谓技术手册就是 Datasheet，里面介绍了整个芯片所有的电气属性，包括：

1. 引脚连接图；
2. 所需的电压电流条件；
3. 芯片内部的寄存器数据；
4. 封装的具体规格参数。

有些芯片厂商会直接附带对应的封装，如果没有的话，就需要我们自己进行绘制。这一部分往往是在 PCB 绘制当中耗时比较多的环节，因为确定需求之后，往往需要对芯片进行选型。即便知道了芯片的型号，它也可能有一些细微的参数改变，这部分就需要硬件工程师进行整体把控。

### 电路设计

绘制原理图首先要确定电路设计。datasheet里往往会有该芯片的参考设计，如果是复杂一些的芯片，则通常会有参考设计原理图PCB文档。

这个过程非常考验工程师的整体经验。本质上，工程师首先需要统筹各个芯片所需的条件，包括电气属性以及连接接口的适配；同时，还需要综合考虑整个文件在 PCB 绘制当中的合理性。

当然，现代数字电路的原理图绘制是比较简单的，只需要简单地把 A 连接到 B，再把 B 连接到 C，再考虑电源部分就可以了。但是，在一些模拟电路或者是高频、射频电路的绘制当中，则复杂的多。首先，是要有设计模拟电路的能力，这一部分很多时候需要进行先验。通常是通过电路仿真来进行，一些复杂电路还需要进行实物仿真，就是先画一个简单的 PCB，验证成功之后，再把这个电路搬到我们要真正处理的电路上面。

这个过程非常考验设计能力的，模拟电路对 PCB 走线要求非常高，所以在设计原理图时，就需要考虑元器件的摆放问题和选型调整。比如模拟电路中一般会有一些放大电路，像仪表放大器，它们对电阻和电容的匹配要求是非常高的，在原理图设计阶段就必须要考虑在内。

像一些射频电路则更是如此，射频电路需要通过射频模拟软件进行进一步的模拟，并在模拟过程中进行调整。有些时候，它还需要像模拟电路一样进行实物验证，搭配频谱分析仪和矢网分析仪进行总体验证。

总之工程师在这一阶段要去反复考证，如果出现问题，就要及时在原理图上进行修改。所以，其实很多模型厂商针对这部分做得并不是很好，他们的主要思路是在于如何在原理图完成的情况下进行 PCB 的绘制，而事实上，原理图的设计也是至关重要的，<mark>可以说现在的最先进的大模型也没有电路设计的能力</mark>。

### 原理图编译

当原理图绘制完成之后，就需要进行第一次查验。这次查验主要是检查所有端口是否都已连接，以及是否连接到正确的位置上。所有未连接的端口都需要进行标注，这样能极大程度地减少漏标或漏画的情况出现。

如果 PCB 容易出现问题，很多时候是原理图出了问题，所以原理图在整个 PCB 绘制的过程中起到了非常重要的作用。

解决了这部分问题之后，接下来就是从原理图到 PCB 的编译，这一过程一般都是由编译器完成的。如果原理图的所有约束关系（包括封装库和电气连接）都正常，我们就可以进入 PCB 的绘制阶段了。

### 结构设计

PCB 的绘制首先要跟结构设计进行沟通，因为设计得再精良的 PCB，如果放不进对应的结构也是空谈。举个例子，现代 PCB 工程设计的标杆就是各种旗舰手机的 PCB，基本上可以达到 10 层板以上，并且板与板直接还要进行堆叠。这对于整个 PCB 的布局来说，实际上是一个极高难度的设计。因为手机的空间非常紧张，大部分区域要留给摄像头和电池，真正留给 PCB 的空间，就只有那些很不规则同时非常紧张的一部分区域。

所以 PCB 的设计往往都需要和结构设计负责人沟通。确定 PCB 的外形和主要接口的位置还不够，还要根据结构空间进行高度的排查，避免一切潜在的结构冲突，才能进行绘制。

### 元器件摆放

接下来，就牵扯到了一个比较复杂的元器件摆放过程。可以说，元器件摆放基本上是 PCB 绘制的最重要的一点。它并不是简单的 X、Y 坐标放置，一定要考虑到自身的位置、旋转的角度，以及跟其他器件的配合等等。

我觉得目前专门的 PCB 绘制大模型，并不能有效解决这个问题。首先，它的结构不能完全按照“横平竖直”去思考。现在的一些大模型，只是优先去思考布局所带来的工整性，但这部分其实反而是不重要的。我们优先需要考虑到，在电气条件的约束下，是否能以这样的形式进行布局，工整性反而是后面需要考虑到的。

这就是为什么很多大厂和小厂，PCB 的绘制样式会有很大的差异。很多人讲，为什么大厂的 PCB 又美观又好看，而小厂的 PCB 格式并不规整？

这是因为大厂拥有更多的资源，可以对整个设计流程进行干预。即便对于芯片，他们也可以直接在芯片的设计过程中就考虑到后续PCB的布局；如果遇到封装不合适的情况，他们也可以直接进行更换。价格往往不是他们要先考虑的部分，他们要考虑的是工整性，以及最重要的电气特性。

比如我们都知道华为的电源做得非常好，可以在极小的体积下放大功率器件，功率密度非常高。我们拆解它的器件后发现，所有的器件都是根据设计来的，大部分都是通过非标设计进行定制的。这个成本当然相当高，小厂基本上不会有这样的成本目标。

所以说，目前来讲，元器件的摆放以及衍生出来的元器件选型二次修改，是整个 PCB 绘制当中最重要的部分。不管是工程 PCB 还是开源项目，这个过程都非常重要，因为它是服务于结构和功能的。

这当然是一个非常依靠经验的行为。在我们的实测当中发现，PCB 的元器件摆放是整个过程中最弱的一环。

### PCB走线

反而走线这一部分，因为前人珠玉在前，现在基本上所有的 PCB 软件都自带自动布线功能。

大模型自己生成的线路普遍没有 PCB 自动布线的效果好。当然了，自动布线和人类布线之间也是有一个明显差距的。我觉得这个差距主要体现在数据维度的获取以及工程经验上。

那么在布线的过程中，首先要考虑到元器件之间的布局，以及它所影响到的电气位置。然后，再去考虑电源域和电源域之间的处理。往往一个芯片需要多种多样的电源管理，有些需要 5V、3.3V、1.8V、1.2V，有些还需要恒流源。这些电路需要单独设计，并且要远离数字芯片或模拟芯片。因为开关电源频繁的开关会产生电磁干扰，从而影响模拟芯片或数字芯片的工作。

所以在布局过程中，要将它们布局在外侧，尽可能远离对应的芯片。

但是这个过程不是必须的，只能说是进行人为的取舍。毕竟 PCB 的外层结构就放在那里，如果过分追求这个结构，可能无法满足合理的布局。

这就是 PCB 布局的难点。

所以这部分工作只能由特别资深的工程师来完成，AI 距离这部分还有一定的过程。

刚才讲完了电源的部分，在电源处理完毕之后，接下来就要进行数字电路的连接。

我们需要根据电路和 PCB 的特性进行分区连接。有些 PCB 是纯数字电路，有些是模拟电路，还有一些是数模混合电路。

但不管是哪种 ，优先确保的都是模拟电路的布线。很多时候我们查看模拟电路芯片的 data sheet 就会发现，文档当中经常会使用一个词叫做“尽可能靠近”或者“尽可能远离”。那么就会有一个问题：“尽可能近”是多近？“尽可能远”是多远？这就要考虑你这个 PCB 布局的总体思想。

如果说你对模拟电路的要求非常高，那你就要给它留出充足的空间进行布线。此时，你就可以满足“非常近”以及“尽可能近”这些约束条件。当然，如果你只有比较小的平面空间，很可能满足不了这些条件，就需要进行取舍。

如果整个 PCB 绘制过程中有射频电路，那么射频电路一定是在电路布局过程中最先考虑的一点。因为射频的条件要求非常苛刻，对整个布局几乎没有容错性。如果布局出现问题，很有可能导致射频故障，从而造成严重的损失。即便是布局完成之后，后续的布线如果没有按照设计来，也可能会导致故障。在最后的测试过程中，可能只是改变一个小小的电阻，对于整个系统来说，就是能用和不能用的区别。如果一个电路中拥有射频电路，比如手机芯片的基带到外围天线的这个过程，其中 WiFi、5G、4G 和蓝牙这些部分，其实它们的设计都是独立开的。因为它们的频段有些出入，所以要统筹它们之间的关系，并且不要发生冲突，这是非常难的一件事情。

射频电路以及所有的电路在完成外围线布局之后，往往需要和结构进行再次复核。这个过程主要是将接口和结构的位置一一对应。比如一个电视机盒子，它所需要的电源接口、HDMI 接口等，都需要跟结构设计的外壳进行对应，这样才能保证后续生产出来没有问题。因为在布线的过程中调整，成本是较低的。当布局完成、PCB 布线完成之后再调整，就需要考虑到各种事情，反而会积重难返。

布线一般就是进行人工布线。一些大厂会把约束条件设计得非常严格，通过 PCB 自动布线完成部分工作。当然，这部分工作比较考验计算资源。本质上这是一个求解问题，大厂拥有这些资源，只要投入足够的计算资源，即使条件再严格，也可以计算出一个不错的结果。

如果是人工布线，则需要考虑到以下影响布线质量最明显的因素：

1. 布线的位置、层数、宽窄以及弯曲角度；
2. 过孔的粗细、层数以及个数。

像有一些高频的数字电路，比如 RAM 和 SOC 之间的连接，就需要通过多路并行或串行的高频数字总线，那么这一部分的走线就需要进行差分走线。因为它的频率非常高，每一个电平的持续时间非常短。如果线与线之间的长度差距超过规范，虽然电平是同时发出的，但并不是同时到达的，就会引起时序问题。

所以一般情况下，芯片厂商的 datasheet 中会严格要求每一组线所需的长度规范，有些是 ±5mil，有些是 ±10mil，根据情况和频率而定。

### 铺铜

在这个 PCB 走线完成之后，接下来需要进行铺铜和电压域预分割的处理，这些基本上属于比较专业的知识。

1. 铺铜：
   本质上就是一根非常粗的导线，只是把它变成了一块规则的多边形铜皮。这个铜皮本身具有连接性，可以把一些高功率的器件连接到一块；而且因为铜皮很宽，所以可以过很大的电流。平时走线的话很细，但过一些信号是没有问题的。铺铜和走线可以理解为处理不同载流需求的两种工具，实现的功能都是把A连接上B。

2. 电压域分割：
   主要就是在一整块铜皮上进行切割。比如我们在一块芯片上可能遇到多个电压域（如 3.3V、1.2V、1.8V），我们就可以在表面打过孔，打到电压域这一层，然后通过分割把这一整张铜皮分成几块，每一块铜皮就对应多少伏的电压。这样的话就比较方便。比如一整块芯片用了很多对应电压的引脚，像 3.3V 的引脚，整个芯片上可能会有几十个都需要 3.3V 电压。这个时候，如果我们通过单根线去连接，可能会导致一个问题：一根线经过过孔之后，它的实际载流能力会大幅下降，真正分到末端的可用电流会很小。一旦上大电流，对应的区域就会发热，甚至会烧断产生风险。所以现在会使用这种分域的技术。

### DRC和最终检查

PCB 的绘制过程结束后，就需要进行最后的核验，这个过程一般都会交由 DRC 进行。DRC 是各个 PCB 厂家进行数据处理和核验的程序，它主要检查两点：

1. PCB 的电路是否连接了；
2. 整个 PCB 是否符合你在规则文件中最开始设定的规则。

检查之后如果发现问题会进行报错，等你把错误处理完成，当 DRC 完全通过之后，就可以进行 PCB 打样了。那么 PCB 的绘制过程到此就结束了。

## 总结

对于低频的PCB来讲，其实要求并不是很高，只要能把芯片连接起来，并且基础的布局问题被解决了，整体就不会出什么问题。所以我们可以看到，很多低频板的布局其实是比较灵活的，但是一旦上了高频，空间就小了许多。因为必须要通过这种完整的规则设计，进行风险规避。实际上，在整个布线过程中风险是非常高的，一旦某根线出现布局问题，很有可能导致整个芯片停止工作，所以这是一项非常需要谨慎的工作。

在实际实践过程中，如果某根线的参数与 PCB 生产厂家规定的极限参数过于接近，它有可能会在生产过程中断掉，并且在测试过程中没有被检测出来。等到真正进行SMT测试之后，后果比较严重。

所以说，整个 PCB 的绘制过程就像是走钢丝，本质上是出正确概率的相乘。每一个环节出现的问题，都有可能导致整个 PCB 停止工作或者某个功能不完整，所以整个过程的难度是非常高的。现在大模型的能力，没有几个人敢将他用于真实生产环境，多是进行测试或者完成一些辅助工作。
