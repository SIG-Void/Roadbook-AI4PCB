# Selected papers

A PCB starts with a schematic. Designers then place components, route copper traces and review the design. These papers cover each task and link to available research materials.

## Schematic reading and generation

- [OmniSch](https://arxiv.org/abs/2604.00270 "OmniSch: A Multimodal PCB Schematic Benchmark For Structured Diagram Visual Reasoning") (ECCV 2026) — Can a model locate a component and trace its connections? OmniSch tests these skills on 1,854 schematic diagrams. It scores visual grounding, connectivity and geometry separately. [Project and data](https://www.omnisch.com/)
- [PCBnet](https://arxiv.org/abs/2608.27923 "PCBnet: A Dataset and Automatic Construction of SPICE Netlists from Schematic Images") (ICLAD 2026) — The pipeline turns schematic images into SPICE netlists. The authors report 94.54% mean average precision for component detection and 84.47% end-to-end connectivity accuracy. The repository offers 300 demonstration samples. Intellectual property restrictions limit access to the full source code. [Author repository](https://github.com/ECNUACRush/PCBnet)
- [SchGen](https://arxiv.org/abs/2605.30345 "SchGen: PCB Schematic Generation with Semantic-Grounded Code Representations") (2026) — SchGen generates editable KiCad schematics from written requirements. Its code connects pins by name and places symbols relative to one another. The authors provide adapter weights, training data, and an export example. [Code and models](https://github.com/microsoft/SchGen)
- [PCBSchemaGen](https://arxiv.org/abs/2602.00510 "PCBSchemaGen: Reward-Guided LLM Code Synthesis for Printed Circuit Boards (PCB) Schematic Design with Structured Verification") (2026) — The system derives constraints from component datasheets. A five-stage verifier identifies pin-level errors and guides revisions. Two benchmarks contain 227 tasks that test compliance with the specified structural rules. [Verifier and benchmarks](https://github.com/HZou9/PCBSchemaGen_v2)
- [HWE-Bench](https://arxiv.org/abs/2603.18102 "HWE-Bench: Can Language Models Perform Board-level Schematic Designs?") (2026) — The paper evaluates 300 board-level tasks. Models receive circuit requirements and component datasheets. Static checks test electrical rules, then LTspice simulates circuit behavior. The repository includes a bathroom fan example. [Evaluation code](https://github.com/EDI-Systems/HWE-Bench)
- [PCB schematic symbol generation](https://doi.org/10.1145/3670474.3685944 "An ML-aided Approach to Automatically Generate Schematic Symbols in PCB EDA Tools") (MLCAD 2024) — The method pairs pin numbers with names and recognizes pin direction in package diagrams. It creates an individual library symbol with pins on two or four sides. [Conference program](https://mlcad.org/symposium/2024/wp-content/uploads/2024/07/MLCAD-Program-2024.pdf#page=1)
- [Power converter schematic synthesis](https://arxiv.org/abs/2610.38201 "From Natural Language to Real Schematics: An Automated Workflow for Power Electronics Schematic Synthesis") (2026 preprint) — The workflow selects parts from datasheets, checks transient behavior in ngspice, and exports editable KiCad schematics. The authors test one buck converter and one isolated dual-active bridge, checking simulation results and the netlists exported from KiCad.

## Component placement

- [RL_PCB](https://past.date-conference.com/proceedings-archive/2024/DATA/1040_pdf_upload.pdf "Learning Circuit Placement Techniques Through Reinforcement Learning with Adaptive Rewards") (DATE 2024) — The agents move components and score placements by track length after routing. Each of the nine seed circuits has 3 to 12 components. Six circuits serve for training and three for testing. [Code and circuits](https://github.com/LukeVassallo/RL_PCB)
- [Cypress](https://www.csl.cornell.edu/~zhiruz/pdfs/cypress-ispd2025.pdf "Cypress: VLSI-Inspired PCB Placement with GPU Acceleration") (ISPD 2025) — Cypress uses GPU-based optimization to place noncritical components. Its public benchmarks derive from commercial layouts. This analytical placer provides a baseline for comparing learning methods on runtime, routing completion, and final track length. [Code and benchmarks](https://github.com/NVlabs/Cypress)
- [RL-assisted simulated annealing](https://ieeexplore.ieee.org/document/10652635 "Reinforcement Learning-Based Placement Method for Printed Circuit Board") (ICCCAS 2024) — The authors train an agent to help simulated annealing select component placements. In their tests, runtime dropped by more than half relative to the original algorithm, with comparable placement quality.

## Board routing

- [FanoutNet](https://doi.org/10.1609/aaai.v37i7.26030 "FanoutNet: A Neuralized PCB Fanout Automation Method Using Deep Reinforcement Learning") (AAAI 2023) — Fanout creates short escape paths from crowded pads before the main routing pass. The model learns fanout choices from the board layout and netlist. The authors compare final track lengths on industrial board examples. [Abstract and index](https://mlanthology.org/aaai/2023/li2023aaai-fanoutnet/)
- [PCBench](https://61dac.conference-program.com/presentation/?id=RESEARCH617&sess=sess237 "PCBench: A Dataset for Printed Circuit Board Routing") (DAC 2024 work-in-progress poster) — PCBench represents routing problems and solutions in JSON, including board outlines, nets, rules, and traces. The repository includes augmentation scripts and a reinforcement learning environment. The [dataset entry](data.md#pcbench) gives the counts for each source. [Data and scripts](https://github.com/PCBench/PCBench)
- [PCBWorld](https://arxiv.org/abs/2607.05915 "PCBWorld: A Benchmark Environment for Engine-Grounded PCB Design Automation") (2026) — Agents interact with the KiCad routing engine and receive feedback on their actions. The benchmark includes synthetic board generators and 679 real open-source board designs. Its metrics cover connectivity and design rule violations. [Environment and evaluation code](https://github.com/LGAI-Research/PCBWorld)
- [PCBRouteAgent](https://arxiv.org/abs/2611.08175 "PCBRouteAgent: How Close Are LLM Agents to Becoming PCB Routing Engineers?") (2026) — The planner selects routing order, corridors, and layer changes. KiCad draws the traces. With Opus 5.5, 94 of 99 small boards passed connectivity and design rule checks. Ten of ten medium boards and four of ten large boards passed. Both subsets used two-layer boards. [Author repository](https://github.com/chip-ai-agent/PCBRouteAgent)
- [CADET](https://arxiv.org/abs/2611.16913 "CADET: Construction of PCB Routing Instances with Executable Demonstrations") (2026) — CADET trains a policy on routing demonstrations, then fine-tunes it with reinforcement learning. The authors generated 100,000 synthetic training boards. On a separate test set of 141 medium two-layer boards, single-attempt clean-pass rates averaged 67.2%. [Generation and replay code](https://github.com/LGAI-Research/CADET) · [Test board list](https://github.com/LGAI-Research/CADET/blob/main/cadet/configs/splits/boards_d3b_test.txt)
- [TRouter](https://www.cse.cuhk.edu.hk/~byu/papers/J94-TCAD2023-TRouter.pdf "TRouter: Thermal-Driven PCB Routing via Nonlocal Crisscross Attention Networks") (IEEE TCAD 2023) — TRouter predicts temperature from components, pads, vias, and traces. It uses that prediction to guide trace detours and via placement. The authors use thermal simulation to check the results and publish four unrouted KiCad boards. [Test boards](https://github.com/plutochen1990/TRouterBM)

## Design comprehension and review

- [PCB-Bench](https://proceedings.iclr.cc/paper_files/paper/2026/hash/051f3997af1dd65da8e14397b6a72f8e-Abstract-Conference.html "PCB-Bench: Benchmarking LLMs for Printed Circuit Board Placement and Routing") (ICLR 2026) — Text questions, visual questions and more than 170 complete projects test whether a model can interpret a design. Tasks include identifying component functions and tracing connections. The scores measure the quality of the model’s answers. [Project and benchmark](https://github.com/digailab/PCB-Bench)
- [DRCY](https://arxiv.org/abs/2603.15672 "DRCY: Agentic Hardware Design Reviews") (2026) — DRCY retrieves component datasheets and checks schematic connections pin by pin. For example, it checks whether regulator feedback resistors match the intended output voltage. The paper describes the AllSpice Hub workflow and gives review examples.

## Fabrication and measurement

- [JARVIS](https://arxiv.org/abs/2611.26503 "JARVIS: An Agent That Designs, Builds, and Tests Circuit Boards on Its Own") (2026 preprint) — After a person approved the plan, the system printed, assembled, and tested a 60 Hz notch filter board. The authors measured 50.6 dB of attenuation at 60 Hz. The agent revised the design in KiCad and rehearsed the second version in simulation.
